1Independence: the theory

From events to random variables to a sample.

In probability

Two events A and B are independent if knowing that one happened doesn't change the probability of the other:

P(A ∩ B) = P(A)·P(B)  ⇔  P(A | B) = P(A)   (if P(B) > 0)

Two random variables X and F are independent if this holds for every pair of values (or of sets of values). For discrete variables this means that the joint distribution is the product of the marginal ones:

P(X = xi, F = fj) = P(X = xi)·P(F = fj)   for all i, j

Equivalently, the conditional distribution of F given X = xi is the same for every i (and equal to the marginal of F). Independence is symmetric: if F doesn't depend on X, then X doesn't depend on F. It is also stronger than being uncorrelated: uncorrelated variables can still be dependent, while independent variables are always uncorrelated.

In statistics (on a sample)

With N observations of the pair (X, F) we count nij = number of observations with X = xi and F = fj, and the totals ni· (row) and n·j (column). The variables are statistically independent in the sample (in the descriptive sense) if

nij/N = (ni·/N)·(n·j/N)  ⇔  nij = ni··n·j/N

i.e. every row of the table has the same profile (the same conditional frequencies). The right side is called the expected frequency under independence, Eij = ni·n·j/N. In real data this is practically never exactly true, even if the variables are independent in the population, because of random sampling. So the question becomes: are the differences between the observed nij and the expected Eij too big to be explained by chance?

Pearson's χ² test

  • Hypotheses: H0: X and F are independent in the population; H1: they are dependent (associated).
  • Statistic: χ² = Σi Σj (nij − Eij)² / Eij. It is 0 when the table is exactly "independent" and grows with the distance from it.
  • Distribution: if H0 is true and N is large, χ² has approximately a chi-square distribution with (r − 1)(c − 1) degrees of freedom (r rows, c columns). The usual rule of thumb for the approximation: all Eij ≥ 1 and at most 20% of them below 5.
  • Decision: the p-value is P(χ²df ≥ observed χ²). If p < α (I used α = 0.05) we reject independence. Equivalently, reject if χ² is above the critical value (5.99 for df = 2, 3.84 for df = 1).
  • Strength: the p-value depends a lot on N, so to measure how strong the association is I also used Cramér's V = √(χ²/(N·(min(r, c) − 1))), which goes from 0 (independence) to 1 (perfect association).
Not rejecting H0 does not prove independence: it only means the data are compatible with it (the sample could be too small to see a weak association).

2The dataset

891 passengers of the Titanic.

I used the well-known Titanic passenger list (the 891 passengers of the Kaggle training set, in the version distributed with the seaborn library, file data/titanic.csv). Each row is one passenger, with class, sex, age, port of embarkation, whether they travelled alone, and whether they survived. The main analysis uses:

  • X = ticket class (First, Second, Third)
  • F = outcome (Survived, Died)

It's a good example because the two variables are categorical, the sample is large enough for the χ² approximation, and the question "did the class affect survival?" naturally leads to the association vs causation discussion. In section 6 I also used a simulated dataset of hackers (attack technique × success), where I know the truth because I generated it, and in section 5 any other pair of Titanic variables can be tested.

For example for first class and survived: E = 216·342/891 = 82.9, but 136 survived. Under independence we would expect about 83 first-class survivors and 188 third-class survivors; we observe 136 and 119.

4The χ² statistic and the p-value

How far is the table from independence?

Interpretation

  • χ² = 102.89 with df = 2, far above the 5% critical value 5.99. The p-value is 4.5·10⁻²³: if class and survival were independent, a table this far from the expected one would practically never happen. We reject independence: class and survival are statistically dependent.
  • The approximation is safe: the smallest expected count is 70.6, well above 5.
  • The residuals show where the dependence is: first class has many more survivors than expected (+5.8), third class many fewer (−5.1) and many more deaths (+4.0). Second class is closer to independence. More than half of the χ² comes from the two first-class cells.
  • Cramér's V = 0.34: a moderate association, not just a statistically significant one. (For comparison, sex vs survival gives χ² = 263.05, df = 1, V = 0.54, an even stronger association.)

I wrote my own function for the p-value: since a χ²df variable is a Gamma(df/2, 2), P(χ² > x) is the regularized upper incomplete gamma function Q(df/2, x/2), which I compute with its power series for small x and a continued fraction for large x (same idea as the normal CDF in the last homework). I checked it against scipy.stats.chi2.sf: they agree to all 12+ digits printed (for example 4.549226137662·10⁻²³ for x = 102.889, df = 2), and the χ² statistics agree with scipy.stats.chi2_contingency.

Some things I found with it:

  • Sex × survival: χ² = 263.05, p ≈ 4·10⁻⁵⁹, V = 0.54: 74.2% of the women survived and 18.9% of the men.
  • Class × sex: χ² = 16.97, df = 2, p = 0.0002, V = 0.14: the two explanatory variables are related to each other too (third class was 70.7% men, first class 56.5%). This matters for section 7.
  • Port × survival is also significant (χ² = 29.67, df = 3, p = 1.6·10⁻⁶), but 2 passengers have no port, so one expected count is 0.77 (below 1) and the χ² approximation is not reliable for that table (the explorer warns about it). The fix would be to drop or merge that category.
  • Age group × survival (p = 0.00025): children survived more (54%), but 177 passengers (20%) have no age, and their survival rate is only 29%. Missing data can end up as a category of its own, and here it is clearly not "missing at random".

6Simulated hackers: when I know the truth

Continuing the hacker story of the previous homeworks.

m = 600 hackers each use one technique X (phishing 40%, SQL injection 35%, brute force 25%) and the attack either succeeds or fails (F). I generated two versions:

  • Independent: success probability 0.30 whatever the technique.
  • Dependent: success probability 0.45 for phishing, 0.30 for SQL injection, 0.15 for brute force.
independent version
dependent version

In the independent version the sample success rates still differ (25.9%, 30.0%, 19.1%) just by chance, but χ² = 5.28 is below 5.99 and p = 0.071, so we correctly don't reject independence. In the dependent version p = 3.3·10⁻¹⁰ and we correctly reject it.

I also repeated the independent experiment 10,000 times: the test rejected (wrongly) in 5.03% of the cases, which is exactly what α = 0.05 means (type I error rate). And with the dependent model the probability of detecting the dependence (the power) grows with the sample size:

With only 30 hackers the test misses the dependence 82% of the time (and the χ² approximation is also shaky, since some expected counts are below 5). This is the practical meaning of "not rejecting is not proving independence".

7Association is not causality

What the test does and doesn't say.

The χ² test only says that the two variables are associated: knowing the class changes what we expect about survival. It doesn't say why, and it is symmetric, so it doesn't even say which variable depends on which. Saying "being in third class caused people to die" is a causal claim, and these data are observational: nobody assigned the passengers to classes at random.

Possible explanations other than "class causes survival"

  • Confounding variables: something related to both X and F. On the Titanic the obvious one is sex: "women and children first" was applied, and the classes had different proportions of men (class and sex are associated, section 5). Other plausible ones that are not in the data: where the cabins were (third class was lower in the ship and further from the lifeboats), family size, language or nationality.
  • The test can't separate these effects by itself. A first step is to look at the association inside each group of the confounder (stratification):
women only: class × survival
men only: class × survival

The association survives inside both groups: 96.8% / 92.1% / 50.0% of the women survived in first / second / third class, and 36.9% / 15.7% / 13.5% of the men. So the class effect is not just "third class had more men". But this still doesn't prove causation, because other confounders could be behind it (cabin position, for example, is itself a consequence of the class, so it would be a mechanism through which class acts rather than an alternative explanation). Stratifying also shows something the overall table hides: for men the big difference is between first class and the rest, for women it is between third class and the rest.

When can association be read as causation?

  • In a randomized experiment, where X is assigned by chance, so it can't be related to anything else. In my hacker simulation the dependence is causal by construction, because I wrote the code that makes the technique change the success probability. With real hackers we would only observe who used what, and maybe skilled hackers choose phishing, so the technique would look better even if it isn't.
  • In observational data, only with extra reasoning: controlling for confounders, a plausible mechanism, a consistent effect in different groups and studies, the right time order (the cause must come before the effect).

Two more limits of the test: with a huge N even a tiny, meaningless association becomes "significant" (that's why I also report Cramér's V), and the test only looks at categories, so it ignores any order in them (like First < Second < Third).

Conclusion. In the Titanic data, ticket class and survival are clearly not independent (χ² = 102.9, df = 2, p ≈ 4.5·10⁻²³, Cramér's V = 0.34), and the association remains when we look at men and women separately. This is strong evidence of an association; it's very plausible that class had a real effect (through cabin position, access to the boats, …), but the χ² test alone can't prove a causal relationship.
